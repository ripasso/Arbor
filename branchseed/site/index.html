How it reads the scan

method

Classical image processing end to end. No training data, no GPU, no network, and nothing tuned per case: every number below comes from the same code path run on all twenty-five volumes.

1 · Learn this scan's contrast

Aortic opacification runs from about 85 to 580 HU across the set, so any fixed threshold fails somewhere. The window is read off the lumen itself, then pushed down only as far as the wall will take before neighbouring liver and bowel start counting as vessel.

2 · One footprint, one ostium

Where bright tissue meets the wall it leaves a patch. Separate patches are separate daughters; a common trunk leaves a single patch however soon it divides, which is exactly the rule the brief sets out.

3 · Grow outward, never sideways

Labels spread away from the wall in order of distance from it. A voxel can only inherit from something nearer the aorta, so two branches cannot fuse and a leak into adjacent tissue stays attached to the origin it came from instead of swallowing the abdomen.

4 · Walk the first ten millimetres

Each branch is followed shell by shell to the first bifurcation or ten millimetres, whichever comes first. The seed sits five millimetres along that path; the direction is a line fit to it; the radius is measured on a half-maximum contour in the plane across it, which keeps it sub-voxel on 1.5 mm scans.
